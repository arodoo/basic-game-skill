# Project Starter

A small repo for keeping project conventions, architecture notes, and documentation in a simple, reusable structure.

It is intentionally basic: the point is to provide a clean starting point that can be changed, expanded, and adapted as the project grows.

## Structure

- `AGENTS.md` — top-level guidance for working on the project
- `agents/` — prompts and instruction files
- `docs/` — documentation organized by type

## Notes

This is not a finished framework or a final template. It is a practical base.

If a rule is too rigid, change it. If a document is incomplete, improve it. If the architecture no longer fits, rewrite it.
